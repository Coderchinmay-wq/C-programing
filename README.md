# C Programming Practice & Implementations

A collection of C programming scripts covering data structures, algorithms, core concepts, and problem solutions.

## 📁 Repository Overview

This repository contains C source implementations organized by topic:

* **Data Structures:** Linked Lists (Doubly & Circular), Stacks, Queues
* **Core Concepts:** 2D Arrays, String Manipulation, Prime Number Algorithms
* **Solutions:** Practice problems and reference materials (`.pdf`)

## 🚀 Getting Started

### Prerequisites
A C compiler such as `gcc` or `clang`.

### Compilation & Execution
To compile and run any `.c` file locally:

```bash
# Compile
gcc "2D-Arrays.c" -o 2D-Arrays

# Execute (Linux/macOS)
./2D-Arrays

# Execute (Windows)
.\2D-Arrays.exe
